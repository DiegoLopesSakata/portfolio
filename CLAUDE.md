# CLAUDE.md

Este arquivo orienta o Claude Code (claude.ai/code) ao trabalhar neste repositório.

## Sobre o projeto

Portfólio pessoal de **Diego Sakata**, desenvolvedor backend júnior (Java, Spring Boot, bancos de dados relacionais). Site estático — **sem framework, sem build step, sem bundler**.

## Estrutura de arquivos

```
index.html                       → todas as seções: Início, Serviços, Resumo (com sub-abas), Projetos, Contato
assets/css/style.css             → design tokens, layout e animações
assets/js/script.js              → navegação entre seções, transição em onda, tabs, ripple hover, form de contato
assets/files/CV-Diego-Sakata.pdf → currículo baixável pelo botão "Baixar currículo"
README.md                        → instruções de uso e deploy
CLAUDE.md                        → este arquivo
```

Não introduza um framework, bundler ou gerenciador de pacotes (React, Vite, Webpack, npm, etc.) sem meu pedido explícito. O objetivo deste projeto é continuar 100% estático — isso é o que torna o deploy trivial (sem Root Directory, sem Build Command, sem Output Directory a configurar na Vercel).

## Design tokens (`style.css`, seção `:root`)

- `--bg: #0f0817` — fundo (roxo bem escuro, não preto puro)
- `--surface: #1a1029` / `--surface-alt: #241640` — cards e elementos elevados
- `--accent: #9d5cff` / `--accent-deep: #6d28d9` — acento roxo e gradientes
- `--text: #f3effa` / `--text-muted: #a99bc4`
- Títulos: `JetBrains Mono` · Corpo: `Manrope`

Ao adicionar novos componentes, reutilize essas variáveis em vez de cores fixas (hardcoded).

## Comportamentos importantes — não remover nem simplificar sem confirmar comigo

1. **Transição de página em onda**: ao clicar em um item do menu, um overlay (`#wave-overlay`) com 3 camadas de SVG sobe cobrindo a tela, troca a seção ativa e desce revelando a próxima. A duração em `script.js` (`WAVE_DURATION`) precisa bater com a duração da animação CSS (`.68s`) — se mudar uma, mude a outra.
2. **Abas da seção Resumo** (Experiência / Formação / Certificados / Habilidades / Sobre mim): controladas por `.tab-btn` e `.tab-panel`, independentes da navegação principal.
3. **Ripple (ondulação) no hover dos cards**: `--rx` e `--ry` são atualizados via JS (`mousemove`) para posicionar o efeito onde o mouse entra no card.
4. **Formulário de contato**: não tem backend — monta um link `mailto:` com os dados preenchidos. Se eu pedir integração real (Formspree, EmailJS etc.), pergunte antes de remover esse fallback.

## Convenções de código

- Português para todo o conteúdo visível ao usuário (textos, labels, comentários voltados a mim). Nomes de variáveis/classes em inglês, como já está.
- Sem dependências externas além das fontes do Google Fonts (`JetBrains Mono`, `Manrope`) e dos ícones do `skillicons.dev`.
- Teste manualmente as três animações (transição de página, tabs, ripple) depois de qualquer mudança em `script.js` ou `style.css`.

## Git — regra obrigatória

**Toda alteração de código feita nas sessões do Claude Code precisa gerar um commit imediatamente após a mudança ser validada.** Não acumule várias alterações em um único commit gigante no fim da sessão — cada mudança coerente (uma seção, um bug corrigido, um ajuste de estilo) vira seu próprio commit, na hora em que é concluída.

Mensagens de commit: curtas, em português, no imperativo (ex: `Ajusta espaçamento dos cards de serviço`, `Corrige link do projeto CondoHub`).

Pastas e arquivos relacionados ao Claude (`.claude/`, `CLAUDE.md`, configurações locais do Claude Code) **devem ser versionados normalmente neste repositório** — não adicione nada disso ao `.gitignore`. Se encontrar um `.gitignore` que já ignore essas pastas, remova essa regra.
